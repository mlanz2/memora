# Memora

A cozy, modern website for scripture memorization tracking with a slightly feminine touch.

## Features

- User accounts for personalized tracking
- Submit verses to memorize each week (encouraged on Fridays)
- View public reports from all users for the current week
- Bible book selection with verse input

## Tech Stack

- Next.js
- Supabase (database and auth)
- React

## Getting Started

1. Clone the repo
2. Install dependencies: `npm install`
3. Set up Supabase project and add environment variables to `.env.local`
4. Run the database initialization script in `setup.sql` in your Supabase SQL Editor
5. Start the dev server: `npm run dev`

## Deployment

Deploy to Vercel with the included `vercel.json`.
